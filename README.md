# RareDiseaseBench

RareDiseaseBench tests whether AI agents can integrate clinical, multiomic, and functional data to make decisions around diagnosing and managing rare disease. In each evaluation, agents receive a clinical presentation and must request information from an isolated filesystem, testing their ability not only to analyze data but to brainstorm what is required. Rubric-graded scores assess how often agents reach the right diagnosis and management plan.

This repo contains 2 sample tasks that closely resemble and were built alongside the the benchmark tasks, but were removed from the benchmark to release as public examples. 

The RareDiseaseBench live leaderboard will be hosted at [benchmarks.bio/raredisease](benchmarks.bio/raredisease)
